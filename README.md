
AstraZeneca DCF Valuation
An independent educational project valuing AstraZeneca using a five-year discounted cash flow model in Excel.  

Base case: £126.47 implied value per share, compared with a £137.90 reference price as at 31 December 2025.  

The model includes a revenue and EBIT forecast, WACC calculation, FCFF valuation and sensitivity analysis. The result depends on assumptions about growth, investment and terminal value. It is an educational project, not investment advice.
